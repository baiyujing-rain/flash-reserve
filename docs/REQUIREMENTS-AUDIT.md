## 本次发现并修复

1. 密码原样处理，避免首尾空格被裁掉导致无法登录。
2. 反向代理显式配置后识别客户端 IP，避免全店被代理地址合并限流；默认忽略伪造代理头。小程序登录默认每 IP 每分钟 2000 次，微信身份另设限流。
3. 工作线程必须完成数据库初始化才报告健康，意外退出时拒绝在途请求并自动重建线程。
4. 异步密码校验、账号写入和手机号换取期间发生封禁/降权时，写入前再次验证。
5. 网络分块的中文 UTF-8 正确合并；错误 URL 编码返回 400，避免无效请求影响服务。
6. 自动到期的活动不能通过延长时间重新开放；过期登录会话与陈旧限流计数定期清理。
7. 补充用户登录、后台登出审计，核销设备记录可以区分浏览器终端。
8. 发布过滤环境文件、数据库、日志、私钥、测试产物；GitHub Actions 执行 Windows/Linux 测试、并发验收和生产容器启动检查。

## 正式营业前必须完成

- 门店自己的 AppID/AppSecret、HTTPS 域名、微信合法域名、隐私保护指引及实际联系方式。
- 微信开发者工具编译和真机登录、手机号授权、订阅消息真实送达、小程序审核。
- 在目标服务器、门店网络和真机上测试放号、网络断开恢复、前后台切换及真实峰值负载。1 秒是前台正常网络且仍有库存时的状态更新验收目标；本地数据不是公网 SLA。
- 明确购买码使用时段、迟到处理、退款/取消等门店规则。本版按“预约名额、到店核销”交付，尚无在线支付、退款或用户取消预约功能；这些未列入原始必选需求。

可发布源码并持续验证，不能据此认定微信生产环境已验收。
